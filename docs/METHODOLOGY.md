# Methodology

## Objective
The project develops a warehouse digital twin and decision-support system using the real warehouse dataset shipped with the repository.

## Workflow
1. Data audit
2. Data quality checks
3. Data model design
4. Descriptive analytics
5. Simulation and scenario testing
6. AI decision-support recommendations
7. Explainability and management output

## Real vs derived vs simulated
- Real: source CSVs shipped with the dataset
- Derived: KPIs, product summaries, flattened storage tables
- Simulated: what-if scenarios and projected performance changes
- Assumed: explicit missing business variables, only when unavoidable

## Academic perspective
The project is designed to support management decision-making with visible evidence and quantifiable trade-offs rather than generic analytics output.
